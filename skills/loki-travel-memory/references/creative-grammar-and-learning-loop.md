# 创意语法与持续学习

在检查重复、裁切和抢声之外，还要主动设计与旅行相符的结构和转场。创意不能靠“更炫”三个字生成；要从旅行类型、素材条件、声音和相邻画面的真实关系中长出来。

## 先判断这趟片子的主模式

一条片可以有一个主模式、一个次模式。不要每到一个地点就换一套语言。

| 模式 | 结构抓手 | 适合的画面关系 | 声音与文字 | 应避免 |
|---|---|---|---|---|
| 城市散步 / 人文观察 | 路线、街区变化、偶遇与个人视角 | 招牌与建筑线条匹配、橱窗/门洞作窗口、人物与城市尺度交替 | 街声先行；文字像地图注记或观察笔记 | 景点清单、每站同一模板 |
| 逛吃 / 食物旅行 | 寻找→上桌→细节→入口→反应→余味 | 菜品全貌与质感细节接力，蒸汽/夹取/切开承接运动 | 锅气、咀嚼前的环境声、真实评价；花字点到为止 | 食物全裁满、每道菜同样快闪 |
| 演出目的旅行 | 期待→抵达→进场阈值→演出证据→散场余韵 | 票、场馆、灯光、观众、谢幕与返程形成前后呼应 | 入场环境声、掌声、安可；无法拍摄时用前后状态完成事件 | 用无关现场冒充演出、整段变饭拍合集 |
| 自然 / 开阔景观 | 接近→第一次揭示→进入尺度→细节→回望 | 地平线、山脊、水流、云雾和人物尺度匹配；大景与微观呼吸 | 允许安静和环境声；文字稀疏 | 所有景都快速推拉、用花哨遮罩破坏辽阔感 |
| 与父母 / 朋友同行 | 共同做事→反应→互动→小状况→回忆锚点 | 行动与反应剪在一起，合影与动态分工 | 优先完整话语、笑声和称呼 | 只剩景点宣传、擅自煽情 |
| 照片主导手账 | 章节空间、主图接力、细节索引、照片组内部关系 | 同一版面中的焦点交接、共享边缘、由总览进入主图、静图接匹配视频 | 文字承担索引而非填空；音乐给照片阅读节奏 | 一张一张贴框、每页同一进出动画 |
| 多日行程 / 多地点 | 大章维持时间感，小节交代具体地点和事件 | 日与日之间用路线、天气、服装、光线或睡醒/返程信号 | 日期只做导航；原声把空缺行程串起来 | 所有天等长、所有地点同权重 |

模式只决定优先判断，不预设固定模板。比如“自然旅行”也可以很喧闹，“独行”也可以幽默；以真实素材和用户表达为准。

## 转场不是效果名，是两个场景之间的关系

先写 `from → to`，再找可见或可听的匹配依据：

1. **动作延续**：抬手、转身、夹菜、推门、抬头在下一镜完成或变奏。
2. **方向与速度**：前景横穿、车窗移动、人物行走方向一致；速度坡度只强化已有运动。
3. **形状与线条**：圆盘接湖面、窗框接画框、山脊接屋檐、道路消失点接走廊。
4. **颜色与明暗**：舞台灯接城市霓虹、雪地高光接白盘、黑场接夜景；不能只因同色就忽略语义。
5. **尺度与构图**：食物细节退成整桌，局部纹理扩成大景，照片内主体位置接下一镜主体位置。
6. **主体遮挡**：人、树、车、门框真实经过画面时做擦除；遮挡物必须来自画面或本次视觉母题。
7. **声音桥**：下一地点的水声、掌声、锅声或一句话先进入；也可让上一场余声带出画面。
8. **图形变形**：地图线、票根、手绘笔触、相框边界转成下一场景轮廓。它应来自本次旅行，而不是通用贴纸包。
9. **时间或意义对照**：清晨/夜晚、期待/实现、累趴/到达、空桌/上菜。允许直接切，让意义自己完成转场。

一个“英雄转场”应同时有两层依据，例如动作＋声音、形状＋颜色。每章通常只需要 1—2 个记忆点；其余用准确直切、自然叠化、布局接力或声音桥。满片英雄转场会让内容失去重点。

如果源素材不支持，按以下顺序降级：真实匹配剪辑 → 声音桥＋直切 → 简洁叠化 → 直接切。不得用蒸汽、冰雾、闪白、镜头旋转等遮罩掩盖无关场景。

## 照片之间要形成“焦点接力”

照片主导片需要设计连续空间，而非不断换相框：

- **主辅交接**：先让主图占据主要视野，辅助图补地点、材质或人物反应；下一拍让辅助图接替主位，旧主图退出。
- **共享边缘**：两张照片用河岸、桌沿、建筑竖线等形成共同边界；边界移动时完成换组。
- **总览到证据**：联系表或多图索引只短暂建立集合，随后进入真正值得看的主图。
- **细节到全貌**：局部纹理、食物切面、小物件先出现，再让完整场景接管；不能把所有照片都裁成细节。
- **静图到视频**：选择构图、主体位置或动作起点相近的照片和视频；视频接管后应成为主画面。
- **平行时刻**：人物与所见、制作与成品、白天与夜晚可并列同屏；它们必须表达关系，而不是为填满画面。
- **节奏波形**：一组可快速建立信息，下一张主图必须给足观看时间；快慢来自内容层级，不来自固定秒数。

每个照片组在分镜上标出第一视线、第二视线和退出方向。若观众第一眼不知道看哪里，先改布局，不加动画补救。

### 单焦点交接，不做多物体搬家

焦点接力的核心是观众知道下一眼看哪里。一次转场默认只有一个主图发生接管：放大、扩展、移入主位或从视频窗口变为全幅；其他照片保持原位、短暂静止、淡出或被主图自然覆盖。避免三张图同时移动、互换位置、交叉穿越或一边缩小一边跑向不同角落。需要表达 01/02/03/04 等连续进度时，编号承担导航，画面仍逐个接管，不能把编号变成额外装饰噪音。

渲染检查不只看首尾静帧。抽取转场 25%、50%、75% 三帧，确认任何中间态都只有一个明确焦点，主体没有被临时裁坏，旧图和新图没有形成意外遮挡。若中间帧乱，缩减运动对象，不能靠加速掩盖。

### 先做内容保护，再做版式

为每张主图标记不可遮挡区域：脸、食物主体、湖面、山脊、瀑布、建筑轮廓、关键动作与视线方向。照片条、自拍组、花字、角标和贴纸只能进入负空间。重要大景先给一拍无干扰的完整观看，再在下一拍单独展示人物或自拍；不要把人物条压在湖面、山脊或景物尺度参照上。设计是否新奇不能抵消内容被挡住。

### 每个画面只保留一个主要信息

导航文字、同期声字幕、花字和解释性小字不是越多越完整。一个画面优先保留必要导航，再从花字、进度编号、解释文字中选择真正增加信息的一项。照片已经能表达“好看”“好吃”“走到了”时，不再用多行小字复述。强调文字随所属画面或字幕退出，避免上一拍的信息残留到下一拍。

## 用“母题”让每趟旅行真正不同

从素材里选一个反复出现、可以变化的母题，例如楼梯、窗、河流、票根、夜灯、圆盘、树影、蒸汽、路线或某个真实小物件。母题至少在两个章节中以不同方式出现：一次做构图，一次做转场或文字承载。它不是水印，也不能压过照片。

建立设计预算：

- 一个核心母题；
- 两种主要照片运动家族；
- 一种导航系统；
- 一种同期声字幕系统；
- 一到两种强调花字；
- 每章一到两个英雄转场。

超出预算的新效果要说明它解决了什么内容问题。不能因“还没用过”就加入。

已获认可的视觉世界应视为项目资产。后续升级优先改照片关系、内容保护、动态和节奏；不能为了证明版本差异，突然把已经通过的材质、颜色和图框全部替换成另一套通用模板。结构相似度、画面差异率或 SSIM 只能说明“变了多少”，不能证明设计更好。

## 先画信息密度曲线

在排时间线前，把全片分成 `吸引—建立—深入—释放—峰值—余韵`，再标每段的信息密度、照片数量、原声占比和主景停留。多日片不必每天同样起伏；峰值应属于这趟真正重要的事件。

- 密集段：用于抵达、逛吃集合、城市碎片或准备过程；画面多，但每张都提供新信息。
- 展开段：用于人物、代表性食物、重要建筑和风景；减少同时出现的元素。
- 留白段：允许一段环境声、完整动作、慢镜头或静止主图，让前面的信息被消化。

如果连续 20 秒都同样密，片子会像快闪；如果连续 20 秒都只有单图慢推，会像翻相册。

## 持续学习，不收集表面特效

每个新项目开始时，至少检查一部近期同类型完整作品，确认现有方法没有把这种旅行剪成旧项目的换皮。如果目的地、主体或主要素材条件是新的，用户明确要求提高创意，或者代表性小样仍显得规整无惊喜，研究至少覆盖三类参考：同类型完整作品、一个邻近类型作品、一个转场/动态图形案例。已经完整观看且仍适配的参考可以复用，但要记录日期和本次适配判断。

记录：

`来源 / 作品类型 / 实际观看范围 / 可见事实 / 声音是否实际听过 / 技法 / 所需素材条件 / 可迁移部分 / 不适配部分 / 在本项目中的小样结果`。

证据层级必须分开：连续观看、抽帧、作者页面说明、第三方拆解、教程演示、搜索摘要。没有看到动态中间态，就不能说“这个转场很顺”；没有听到声音，就不能说“卡点准确”。

每次只把通过真实素材小样的判断升级为个人默认。具有作者辨识度的标志性转场只能分析原理，不复制成一模一样的镜头。

静态设计稿只用于判断构图、层级和遮挡。运动与音乐相关的方案必须进入连续动态样片：使用真实素材和拟用音源，至少包含一个照片焦点交接、一个信息密度变化和一个音乐/章节边界；抽取中间帧并连续播放。样片没有成立前不扩展全片，也不以“首尾静帧好看”推断转场顺畅。

这是一项在 Skill 每次执行时触发的学习步骤，不把它描述成无人运行时仍会自动监控互联网。新发现先进入项目研究记录；只有跨两次以上项目仍有效，或用户明确确认偏好，才升级为长期规则。
