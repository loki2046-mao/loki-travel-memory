# 配乐、同期声与听审

## 从用户的音乐偏好开始

已有歌名、歌手或参考线索时优先确认版本和用途；未知时给少量有理由的候选。不把一次旅行的歌单固定成模板。区分曲名、作者、音源出处、试听可用、可导入文件和使用许可；能播放不等于能公开使用，不从参考影片提取歌曲分发。

## 音乐与画面共同排剪

有对白先保护完整意思和反应；照片段可先选乐句再排版。实际听音乐的强弱、起落、句尾，再挑切点；节拍检测和波形只提供候选。不能每拍必切，也不能用均分秒数代替内容节奏。

下一首歌代表新章节时，默认随所属画面进入。若歌曲比画面先结束，优先调整画面、用同场环境声衔接或共同收口。只有存在内容桥梁且实际听起来成立时才提前引入，记录原因；交叉淡化不能让两首歌的歌词打架。

## 同期声

短引导句可把音乐压低垫在下方，避免骤停。重要现场声可以独立出现。连续说话不要夹几秒音乐和图片；不要叠两段对白。保留字头、尾音和反应，剪口独立于照片时长，相关照片可以承接完整话语。

先转写定位，再听原声核对字词、语气和噪声。不能拿字幕文本证明听得清。指向特定景物的语句要和画面对应，不能在旧地点上提前说新地点的眼前事物。同事件声音桥可以跨画面，不捏造不同事件的连续性。

同期声字幕需要可读底板，与导航、花字区分。解释一句话的花字若绑定该字幕，结束误差不超过一帧；图片花字随所属图片退出。参见 [时间线契约](timeline-review-contract.md)。

## 片尾

最后一句话结束后，音乐不能先突然恢复大音量，再被截断。单独设计尾音：保留余韵，按乐句和最终画面连续收束。检查混音和分轨，区分同期声起音与换歌剪口。

## 验收证据

完整连续听审之外，重点回听换歌、对白进出、连续说话、片尾各区间；记录实际时间范围、发现的问题和修订。输出试听片段便于复核，但片段不等于全片听审。

人工听审、音频模型分析、ASR、响度/波形、解码检查分别记录。技术检测通过不能记作人工听审通过。工具无法可靠听音时，把成片标为待听审，并给出重点区间；不宣称已经完整听过。音轨哈希一致只能证明内容未变，不能证明自然好听。
