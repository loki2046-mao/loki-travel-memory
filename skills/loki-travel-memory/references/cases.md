## 本轮真正改变的决策

1. 先判断是完整成片、片头示范还是教程；三者不能共用节奏结论。
2. 照片手账优先建立稳定视觉框架，再决定动效，不先给每张图加动画。
3. 家庭选片单元从单镜头升级为行动与反应的事件组。
4. 照片既可融入过程，也可作为尾声；不固定照片/视频比例。
5. 开头可用多种记忆意象，结尾可用普通生活，无需强行煽情。
6. 配乐署名、教程卡点操作和实际听感属于不同证据，分开保存。
