# 选片与结构

参考方法来自 [案例研究](cases.md)，属于候选手法，不能替代对本次素材的判断。

实际制作先遵循 [本次偏好](user-profile.md)、[精选规则](selection-and-review.md) 与 [章节设计](story-and-design.md)。本文保留参考案例带来的候选手法，不能覆盖当前用户的偏好。

## 先组织事件

将素材分为环境交代、人物行动、细节、反应、合影和收尾候选。同地点三张图若承担不同作用，可以同时保留；十张近似风景一般不需全留。无法看到参考片的未选素材，不能声称知道作者为什么删掉某张图。

家庭素材先找做事的人和反应。F1 饭桌段落以食物、自己试吃、父母吃饭形成关系。把动作与反应作为一个候选单元，不只剪最清晰的一秒。

交通/住处镜头需承担地点转移、一天的开始或事件引入；无信息增量仍可删，不因参考片有车窗而强加车窗。

## 按素材选择结构

| 素材特点 | 优先结构 | 避免 |
|---|---|---|
| 照片多、短视频少 | 事件分组的照片手账；动态作节点 | 所有照片等长、相同推拉 |
| Live Photo 多 | 短动态与静图组成序列，统一框架 | 默认低帧率或反复循环 |
| 家庭对话与互动丰富 | 事件推进，保留完整反应 | 全切成三秒碎片 |
| 视频叙事完整，另有合影 | 纪实主体加照片式尾声（F2） | 强行每分钟插照片 |
| 孤立风景和摆拍为主 | 短相册或音乐精华 | 虚构事件和父母心理 |

F2 先用旅途意象短预告再进入出发，适用于有多种记忆锚点的素材；不是强制钩子公式。原声更好时直接现场开场。

结尾可选照片回顾与题字（F2），或仍在发生的普通生活（F1）。依据这一趟如何自然停下，不默认升华。

## 三种照片组织工具

固定框架、内部改变（P2）：先定底色、照片区、文字区、装饰笔触，再换素材。保留不同照片比例，一个时刻一个主要观看对象。文字补信息，不挡脸。不复制黑底与歌词为默认；给父母看时优先完整人像、字号和停留。

多图总览到单图（P1）：用于章节入口或尾声，少量照片先建立记忆集合，再进入其中一张。重要合影仍需独立展示，不能为塞更多图而缩到看不清。

人物抠图拼贴（P3）：用于少量片头/标题，要求轮廓清晰、动作有差异。抠图丢失地点证据，随后补完整场景。抠图差时退回整图，不能因为工具支持就强用。

## 动态和适配

照片运动应揭示内容，先保护人物与可读性，再考虑堆叠、换背景色、抠图入场。P1/P3 的快节奏包装不能证明家庭主体也应如此密集。

教程要求卡点只证明作者在教授这种方法，不证明参考成片每次切换都准确对拍。

横竖适配需重新布局；分析联系表为适配补出的黑边不能当原片设计。以媒体尺寸确认原画幅。低清分析副本适合判断大构图，不适合评价压缩细节和肤色。
