# 轻修图、工程与验收边界

## 非破坏式轻修

原片保留。修图输出独立版本，记录 source_id、版本、裁切/调色/局部修复操作；时间线引用可追溯。不要为所有照片统一套强滤镜。

1. 先决定主图和版式，再修入选图，避免浪费在未选素材上。
2. 常规处理：轻微拉直、裁切、曝光/白平衡/对比度与饱和度调整。最终导出前逐张分析入选照片，按每张原片的曝光、色温、黑白场、主体与场景单独决定参数，禁止用同一 LUT 或统一滤镜替代。人物保肤色，食物保留可信色泽与纹理，夜景保黑位，星空不抬成灰雾，雪山、水面和天空保高光层次；同一事件协调色彩，跨事件保留有意义的时间与环境差异。
3. 小角落干扰先试裁切。裁切会伤主体时，可做局部清理，但仅处理无叙事意义的边角杂物。不能顺手删除同行的人、地标结构、演出舞台内容或改变食物形态。
4. 涉及图像编辑时遵循当前工具要求：按宿主支持的工具和用户授权执行；生成式局部修复不能替代常规逐图调色。先查看原图，说明只改局部、保留其余画面，但不能把提示词约束当作实际保真证明。
5. 对照修前修后，检查主体形状、纹理、文字、人物、边缘接缝是否意外变化。保留逐图调色参数或代表性前后对比，另外连续查看同一事件，防止相邻照片忽冷忽暖或亮度跳变。生成式修复若改变主体，退回裁切/原片方案。没有查看不能标记通过。

用户已授权的轻修不逐张重复询问。会改变事件或主体含义的改造不属于轻修；优先放弃改造，确实必要再指出具体变化请求判断。

## 一次旅行的可重建交付

素材清单保留来源和时间置信度；选片表遵循 [初筛与复选](selection-and-review.md)。设计单遵循 [章节与设计](story-and-design.md)。这些是制作数据，不要求用户逐一填写。

时间线每个条目至少记录：事件、来源文件/修图版本、源入出点（视频）、成片起止、版式及图像位置/裁切、动效参数、文字、声音来源与起止、选择目的。多图页逐图记录，不能只保存一句“这里做照片墙”。源时间与成片时间不能混用。

保留可用工程或可重建渲染脚本、成片、音乐来源、排除/备用清单、修订记录。实现能力不足时说明具体缺项，不能把一份 JSON 或指令文档称作自动剪辑软件。

## 分层验收

- 选片：同组确实比较过；最好看与最有记忆意义没有混为一个分数；没有为了版式凑图。
- 轻修：实际对照原图；无主体变化、过度锐化、失真颜色或错误文字。
- 视觉：看实际渲染；节奏判断需连续播放，联系表仅检布局。
- 声音：实际听审音乐、对话、环境声及衔接；无能力时明确未验证。
- 技术：文件可解码、时长画幅正确、无丢帧黑屏等；技术通过不等于观感通过。
- 用户体验：复选确实少且分段；修改能落到具体事件/照片；不让用户重新整理全部素材。
