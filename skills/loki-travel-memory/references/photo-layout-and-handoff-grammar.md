# 照片编排与焦点接力语法

这份参考提供照片版式与图片切换的可组合方法。它们是可组合的设计语法，不是下一趟旅行直接换图的模板。先判断内容关系，再选择语法；颜色、材质、图框、比例和文字都要从新旅行重新推导。

## 共同原则

1. 每一拍先确定唯一主角：一张照片、一段视频或一个需要读懂的关系。
2. 辅助图提供地点、细节、人物反应或下一焦点，不以“填满版面”为目的。
3. 一次切换只交接一个焦点。旧主图淡出或保持，下一张从它原来的细节位接管主位；其他图片后出现，不交叉搬家。
4. 版式随内容变化。大景、人物、食物、夜空使用不同阅读逻辑，但沿用本项目的颜色、材质、图框与导航系统。
5. 文字、编号和装饰只承担导航或强调。照片已经说清楚的内容不再加解释性小字。

## 语法 A：逐张全屏曝光

适合星空、海面、夜景、舞台灯光等同一主题、每张都值得完整观看的照片组。

- 照片本身占满画幅，项目材质只保留在边缘或角落，不能把照片缩成底板上的卡片。
- 01—04 等编号表示当前看到第几张；它是进度，不是常驻缩略图墙。
- 当前照片最亮，其他编号降权。开场可有一句短花字，建立情境后立即退出，让画面恢复干净。
- 下一张在真实音乐强拍前做约 0.18—0.30 秒短叠化，并在鼓点/重音到达时完全接管。只做曝光式替换，不滑入、不翻页、不让多图碰撞。
- 每张可有极轻微推近，但幅度只用于保持呼吸，不能伪造明显运镜。

星空可用“四张照片依次接管全屏＋01—04 进度＋短叠化”。可迁移的是曝光序列和焦点纯度，不是固定四张、固定秒数或冰纹边缘。

## 语法 B：主图＋异形细节接力

适合同一地点中既有代表性大景，又有水纹、树木、食物切面、小物件等细节的照片组。

- 主图约占观看面积的 60%—70%；两到三张细节图大小不等，围绕主图形成方向明确的阅读线。不要做等大三格或固定右侧缩略图栏。
- 细节图必须扮演不同角色，例如“空间线索、材质证据、下一焦点”，不能是近重复照片。
- 可用一条来自内容的共享线索连接阅读顺序，例如溪流、道路、桌沿或建筑轴线；线条保持稳定，不与照片同时抢动。
- 切换时，选中的细节图从原位置连续扩展到主图框；旧主图与未选细节只淡出。新一组辅助图在接管完成约 70% 后再出现。
- 下一拍继续从当前组的一张细节图接管主位，形成 `主图 → 细节成为主图 → 新细节补入` 的连续链，而不是整页同时换掉。
- 交接落在真实节拍或乐句节点；如果音乐没有合适脉冲，使用稳定叠化或声音桥，不强行卡点。

溪流场景可用大主图、两个不同尺寸细节位和一条水流阅读线。右侧细节逐个扩展为主图，其他面板淡出，没有交叉换位。

## 语法 C：先完整看景，再另起人物证据页

适合雪山、湖泊、建筑全景、演出舞台等画面主体本身需要完整空间的场景。

第一拍只看大景：

- 全幅或近全幅展示，先保住地平线、山脊、湖面、舞台和前景尺度。
- 导航只进入安全区；不叠自拍条、花字、贴纸或小图。
- 让观众先建立“我在哪里、这里有多大”。

第二拍再看人物：

- 使用一大两小、一大三小或其他有明确主次的人物页。
- 选择角度、动作或表情有差异的照片；编号只表示阅读顺序。
- 人物页可以延续前一拍的颜色和图框，但不能覆盖回前一拍的大景。

从大景到人物页可用一次克制的版式收拢、构图匹配或音乐弱拍直切。不要把人物缩略图直接压到大景底部，造成“景和人都没看清”。

## 语法 D：完整主菜＋热乎细节

适合有一个核心菜品，同时有汤、蒸汽、夹取、切面或锅气细节的吃喝段。

- 完整主菜占主位，保证盘子、锅和食物形态看清。
- 一个较大的动态/细节位承担温度和口感；其余信息用一句有内容的短花字收束。
- 花字放在独立负空间，不压食物。若同期声已表达评价，花字只提炼一个重点，不重复整句。
- 动态切换优先使用蒸汽、夹取、开锅或端上桌等真实动作；没有动作时，用主菜与细节的尺度接力，不套食物快闪。

## 从静态版式变成动态的顺序

1. 在静帧上标出主图、辅助图、下一接管者和不可遮挡区域。
2. 为每次交接写 `focus_owner_before → focus_owner_after`；默认 `moving_focus_layers` 只有下一接管者。
3. 先渲染 3—15 秒连续样片，使用真实音乐；不能只导出首尾两张设计稿。
4. 抽取转场 25%、50%、75% 三帧，检查中间态是否发生交叉、遮挡、突然换位或多焦点竞争。
5. 连续播放并实际听剪口。节拍检测只提供候选点；画面必须在音乐重音/乐句边界完成接管，而不是提前或滞后。
6. 样片成立后，再把相同语法用于同一章节的其他照片；每章最多保留一到两种主要运动家族。

## 选择与降级

- 同主题照片都值得完整看：选逐张全屏曝光。
- 一个大景带多个有信息增量的细节：选主图＋异形细节接力。
- 大景和人物都重要、同屏会互相遮挡：选先景后人两拍。
- 核心食物加质感细节：选完整主菜＋热乎细节。
- 素材不支持明确关系：降级为单图、克制叠化或直切。不要为了使用语法而凑图。
