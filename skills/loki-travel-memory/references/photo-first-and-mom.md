# 照片主导制作与妈妈个人片

面向照片主导旅行，也支持按请求为同行者单独剪片。

## 照片本身承担叙事

不设最低视频比例，不把照片做成等待视频串联的配角。先从精选照片形成完整段落，再判断少量视频能增加什么。没有视频时也能成立；视频有动作、表情、环境声或事件发展才加入，不能因文件是视频就优先。

面对大量照片，先按事件与重复组收敛数量，再按篇幅和叙事作用分配版面。不要平均展示所有“还不错”的照片，更不能用加快播放塞满。精选但未入片的照片可留在精选目录，成片不承担完整相册的职责。

照片段落通过主图与细节、景别、横竖比例、人物与环境、留白和多图关系形成变化。静止的好照片可以充分停留；动感主要来自布局变化、逐张出现、视线引导与章节节奏，不要求每张推拉摇移。多图页不是提高塞图容量的工具。

少量视频可成为节点：静态风景之间的一阵风、人物照片之间的一次转身或笑、演出章节的掌声。先判断它能否打破重复或补充现场感；不要机械地每几张照片插一个视频。不能用生成动作冒充真实旅行录像。

## 按请求选择主角与输出

| 请求 | 选片中心 | 结构中心 |
|---|---|---|
| 给我做这趟旅行回忆 | 旅行者经历过的事件与审美 | 本次旅行如何展开 |
| 单独给妈妈做一条 | 妈妈好看的照片、自然动态与她参与的经历 | 她在这些地方的状态与活动 |
| 两条都做 | 共用素材分析，分别做取舍 | 两条独立时间线，不能只换片头标题 |

没有要求时不自动生成两条增加工作量。两种版本共用原素材、分组、去重和可复用的修图版本；人物优先级、选图、节奏、文字和声音分别决定。某张风景在 旅行者版本是主图，在妈妈片可能只是地点交代；某段妈妈的动作在个人片可完整保留，在旅行片可短用。

## 妈妈个人片的选片与设计

先在同一场景/服装/姿态的候选中选表情自然、姿态好看、面部清楚、光线与构图合适的主图，再选不同景别或动态。区分重复摆拍与有价值的姿态变化，不用模糊的“颜值分”排序。全身照检查头顶、手脚与身体比例，半身照检查面部与背景干扰。

优先充分展示好的人像。多图页可以用一张大人物图配环境/细节；避免四张脸都小到看不清。环境交代服务于“她在这里”，但不必每一秒都有人像。保留自然走路、转身、笑、看景等可用动态，不能机械套慢动作。

不默认磨皮、瘦脸、瘦身、减龄、夸张滤镜或年龄化装饰。轻修沿用保真规则。妈妈喜欢照片视频不代表已知她喜欢某首歌或某种“妈妈模板”。按实际素材给出有审美依据的主方案，有反馈再调整。

人物身份不能仅凭外貌猜测。现有上下文无法确认哪位是妈妈时，只需展示少量编号参考图，请用户一次指认；不要逐张确认身份。

## 默认少打扰，先承担判断

用户提供素材位置和制作对象后，先清点、筛选与组织。缺失信息中，只有无法继续的项才提问；画幅、片长、风格等可根据素材和已知用途先提出合理假设并推进。别让用户填长问卷、手动分文件夹、给全部图片打分或逐页批准。

两张接近但都可用时，默认由 agent 选；不因低置信度就把所有审美判断上交。只有涉及未知重要人物、必留意义或无法判断的核心事件才集中询问。用户明确要求参与挑选时，按 [分段复选](selection-and-review.md) 执行；用户说“你定”后不重复发相似选择题。

成片请求以可播放初版为阶段交付，不停在分镜和模板清单。接收“这张妈妈不好看”“这段再多留一点”等反馈并定位修改，不能要求用户重新选一遍。

多次制作保留每趟素材索引、选片状态、设计决定、时间线版本、已验证和未验证项，便于中断恢复。新增素材仅重新评估受影响事件，不覆盖已确认选择。用户明确反馈记录在旅行工程，需成为 Skill 通用偏好时注明来源，不自行写入独立记忆系统。

## 能力边界

这是制作工作流，不内置通用人物识别、审美评分或一键渲染引擎。每种人物版本都需要独立检查选片、连续播放和声音，不从另一版本推定通过。
