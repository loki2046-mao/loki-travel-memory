# 从个人经历组织章节与视觉设计

## 章节跟着经历，不跟着文件夹

按天、按地点也是正式结构；日期可靠或用户希望按天时，采用“天 → 地点/事件”的层次，具体见 [行程与声音串联](itinerary-and-voice.md)。不强行把清楚的日记结构改为主题蒙太奇。

先写一句本次旅行的实际主线，再确定哪些事件推动它。演出可以是缘起与高潮，咖啡、散步和朋友是通往它的经历；如果实际只是随性逛吃，就用地点/一天的流动组织，不硬造戏剧冲突。

示例仅是结构演示：下午到城 → 咖啡店歇脚 → 沿街逛 → 入场期待 → 谢幕余韵 → 夜宵回程。自然、人文、吃喝不必各自剪成互不相干的合集。时间不明确时用主题关联，不虚构“演出之后”或具体日期。

每个事件先确定观看重点，再选环境交代、主角、细节、动态/反应和离开的组合。素材不足可短到一页，不强行补齐五类镜头。突出真正重要的事件，不能按照片数量平均分配时长。

演出没有正场素材时：已有的场馆/入场照片建立事件 → 标题或留白过渡 → 真实安可/谢幕 → 之后的实际素材。可以省略中间过程；不加入假票根信息、合成舞台回忆或没有发生的观后感。

朋友/父母段落保留相处方式，独行段落也可鲜活热闹。没有用户明确表达，不写孤独、亏欠、衰老、治愈或“终于学会”等心理旁白。

## 每次旅行的设计任务

根据这趟的光线、色彩、城市/自然环境、事件与照片比例，先给出一个有理由的主方案。不要默认让用户在九套设计里做选择。风格不确定且实质影响成片时，再给少量差异明显的方向。

设计单必须写清：视觉概念、取自素材的依据、颜色、字体层级、画幅、安全区、图框和材质、2/3/4 图构图、主次、文字位置、运动方式、章节转换，以及哪些装饰不用。选定一种主要视觉语言，允许章节变奏，不能每页像另一支影片。

新旅行若要区别前作，比较构图、图框几何、图像占比、文字密度、材质、动态方式；不能只改标题和底色。也不为了不同而牺牲照片。照片墙不是唯一样式，全屏照片与视频可穿插。

已通过的项目视觉方向应作为约束继续深化。后续版本优先优化照片关系、运动、内容保护和节奏，不能为了“看得出改了”就把整套底板、图框和材质换成另一种通用模板。

## 可组合的版式语法（不是固定皮肤）

可选的“逐张全屏曝光、主图＋异形细节接力、先景后人、完整主菜＋热乎细节”及其动态顺序，见 [照片编排与焦点接力语法](photo-layout-and-handoff-grammar.md)。下面表格继续作为通用选择表；两者都只能按内容选用，不能整片机械套版。

| 内容 | 可用构图 | 阅读与动态逻辑 |
|---|---|---|
| 同一物件整体与细节 | 大主图 + 小细节窗 | 先看形态，再让细节出现；不能同时三个窗口都运动 |
| 两张互补风景 | 宽幅主景 + 留白中的局部，或上下呼应 | 用地平线/色彩呼应；禁止强裁掉主峰或建筑 |
| 一次吃喝小集合 | 不等大双/三图，简短菜名或日期 | 保持食物色泽，装饰不遮盘子；杯圈/线条只是可选元素 |
| 朋友同场多个时刻 | 大互动图 + 两张反应/细节 | 主图看清表情，小图补故事；重要合影可独占一屏 |
| 四张同主题照片 | 四格或一大三小 | 先检查每张都值得留且小屏看得清，必要时拆两页 |
| 演出前后 | 场馆全图 + 安可照片组；可借海报式层级 | 仅使用真实文本与票务信息；装饰不能冒充真实票根 |
| 沿途偶遇 | 小窗口插入、页边注或短动态插曲 | 前后仍能回到正在走的路，不强开独立章节 |

图框可以是画廊框、纸页窗口、接触印样、旅行图册等；选择由素材决定，不要给每张机械贴胶带。照片原比例优先，裁切需检查主体。多图页有明确阅读顺序，新增一张图就留出看清它的时间。停留以图数、细节、文字与音乐句子决定，不能全片所有页等长。

小动画来自内容：路线线条、日期印记、轻微纸页运动、细节指示等。每一时刻一个主要运动焦点；不让照片、文字、背景和贴纸同时抢动。默认不对照片里的人物生成未发生的动作。

## 内容保护与文字预算

排版前先标出每张图的核心表达区。人物脸、食物主体、湖面、山脊、瀑布、建筑轮廓和关键动作不被自拍条、花字、贴纸、角标或次图覆盖。重要风景先用一拍完整画面建立空间和尺度，再在下一拍展示人物、自拍或细节。若两者无法同时看清，就拆成两拍，不靠缩小主景硬塞。

每一屏只设一个主要信息。章节/地点/日期属于导航；同期声字幕属于可懂度；花字属于强调；01/02/03/04 等编号属于真实进度。四类不能无上限叠加。除字幕外，通常只保留必要导航和一项强调；照片已经表达清楚的内容不再用小字复述。所有文字避开内容保护区，并按所有权随画面或声音退出。

## 照片与视频连接

先为每个相邻场景写镜头对接关系，再实现效果；动作、方向、形状、光色、尺度、主体、声音或意义至少要有一项真实依据。具体转场语法、降级顺序和英雄转场预算见 [创意语法与持续学习](creative-grammar-and-learning-loop.md)，时间线记录字段见 [时间线与验收契约](timeline-review-contract.md)。

- 同一对象：静态咖啡主图 → 实际拉花/端杯视频，或反向从真实视频帧停住成照片；来自不同拍摄时刻时不要伪装连续动作。
- 同一版式：视频放进照片墙的一个窗口，其他照片保持静态；重要声音/动作开始时扩展为主要画面。
- 同一视觉：以相近色彩、形状或运动方向衔接不同地点，仍需足够地点线索，不能造成空间误认。
- 同一声音：经听审可用的脚步、环境声或对话提前进入下一画面；相关照片可以承载声音。不同事件的声音不用于捏造现场。
- 大章节：沿用视觉系统的标题/地图/时间提示，或以声音和留白过渡。只有实质场景变化才需要章标题；每杯咖啡不必转一次章。

## 音乐与节奏的位置

有重要对白的段落先保完整内容，再安排配乐进入退出；纯照片段落可先定音乐乐句再排版和切页。节拍是可用参照，不要求每次切图都卡鼓点。章节情绪与乐句共同决定换曲；不能每类食物换一首歌。

演出同期声与配乐要听过再决定衔接；掌声、环境声、暂时无 BGM 都是可用选择。歌曲名称、授权与可否发布按实际来源记录，不因“去看了这场演出”就默认整首歌是成片 BGM。具体听审证据见 [声音与验收](audio-review.md)。

## 实现与设计验收

真正制作时，先用本次精选素材实现一个代表性连续段落，包含多图页、视频或动态照片组、一次单焦点交接，以及真实配乐中的一次节拍或章节边界；自己连续播放并抽取转场中间帧，再扩展全片。这不是强制用户批准关卡。设计说明不算渲染，静态版式不算动态验收。

检查：主图是否第一眼看见；小图能否看清；人物与主体是否被裁坏；照片和装饰是否和谐；连续几页是否无意义重复；照片与视频是否亮度突变；音画衔接是否实际听过；结尾是否自然。画幅改变需重新排版，不整体缩小横屏塞进竖屏。

## 具体地点与完整旅行

大日期章不能代替地点小节。每到新地点/用餐事件，用清晰的小标题说明当前是什么；位置角标跟随实际地点，不把住宿小镇、周边景区和主景区统一标成一个地名。名称先查素材中的牌匾，再以官方资料核对；到访顺序依用户确认与拍摄原始时间，记忆不确定时保留差异记录。

底板获认可后保留，单独调整标题签对比度、照片位置、主次与换组节奏。文字位置获认可不等于颜色已通过：DAY、章节主标题和副标题必须分别检查与底板的明度、色相差，不能因沿用位置而继续被纹理吞掉。长原声段应跨几组相关照片，不迫使一张主图停留十几秒。新增素材要重新扫描，包括误放到“照片”目录的视频；补上返程、封面和封底。无影像的菜品或活动不拿其他日期的画面冒充。
