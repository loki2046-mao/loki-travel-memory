# 每趟旅行的原创设计决策

设计目标：贴合目的地、所拍照片的风格与当时心理状态，每次各有特点，不能敷衍套模板。以下是执行与自审方法，不是已证实的自动审美能力。

## 先建立这一次的依据

从实际精选素材形成设计简报，记录：旅行缘起/主角、已确认行程、照片特征（光线、色彩、构图、题材、横竖比例）、重要事件、可用声音、用户直接表达的感受，以及未知项。不要把暗色当忧伤、独行当孤独、海边当治愈。用户没表达心情时，设计可依据可见气氛，但旁白不代写心理事实。允许同一旅行不同阶段情绪不同。

再从 [创意语法与持续学习](creative-grammar-and-learning-loop.md) 选择一个主叙事模式和一个次叙事模式，画出信息密度曲线，并从真实素材中找一个可变化的核心母题。模式、母题和曲线都必须写出素材证据；不能因为目的地属于某类，就直接套用那一类的视觉皮肤。

没有用户素材时只做条件式设计研究，不替尚未见到的旅行拍板风格。目的地不能只变成地名、地标贴纸和刻板文化符号；实际拍到的街道线条、门窗、植物、灯光或票面形态更能提供设计依据。

## 内部探索，用户少做选择

先内部提出三个有结构差异的设计假设，比较适配与制作可行性后推荐一个；不默认把三套都变成用户问卷。每个假设写一句概念及素材证据，说明开场、阅读顺序、图像占比/裁切、图框几何、文字密度、运动方式。候选之间至少在其中四项有实质差别，不靠换色命名。

从不同参考中提取不同层面的原则：一条参考的照片阅读顺序、另一条的章节结构、第三条的声音连接。不能拼贴所有效果，更不能复制标志性画面。选一个统一的设计逻辑，再让章节有变奏。

设计决定须能回答“为什么适合这批照片/这次经历”。例如“海边所以蓝色”不足；“照片多为宽阔水平构图，使用宽幅窗口与横向展开，给海面保留面积”才是可执行理由。示例不是海边固定模板。

## 不同输入的条件式策略

| 实际素材条件 | 可探索的设计机制 | 不能机械推导 |
|---|---|---|
| 开阔景色、留白多、细腻光线 | 大画幅与少量局部窗口、低文字密度、较缓的揭示 | 默认煽情钢琴或孤独旁白 |
| 街巷、招牌、食物细节丰富 | 图册式主辅图、局部索引、疏密交替 | 每张贴胶带、字幕铺满 |
| 演出前后、灯光强烈、夜景 | 白天到夜场的密度/对比变化，事件引入与余韵 | 必须做音乐 MV 或整片霓虹 |
| 妈妈人像构图好、服装与景色协调 | 人物大图与环境页交替，保留姿态空间 | 固定“妈妈风”、默认减龄美颜 |
| 多天多地点、画面风格差异大 | 稳定的章节导航，章节内部用不同照片关系 | 每天换一套不相干视觉语言 |

## 用真实片段检验，而不是用形容词交付

制作时选择能代表难点的一组真实素材：主图、多图页、较弱但重要的照片、短视频/同期声（若存在）。实现一个连续段落，检验静态构图、动态阅读、音画连接。没有视频就验证纯照片段落，不添加假视频凑检查。

检查三个层次：
1. 内容贴合：设计依据是否能指向具体素材；主角和重要事件是否被看见；心理表述是否有来源。
2. 视觉成立：主图突出、字体和文字量合适、小图可读、调色不伤原片、留白与密度有变化；去掉装饰后布局仍成立。
3. 时间成立：照片看得清，运动有观看顺序，转场不打断内容；实际听审音乐与语义。联系表不能证明这一层通过。

若任一层不成立，先改最影响观感的问题，再扩展全片。画面不够好时可减装饰、换图或换布局；不能靠堆效果掩盖。成功编码不计为审美通过。

## 跨旅行差异与设计记录

读取用户已有的旅行工程设计摘要（若有）。保留本次概念、证据、图框/布局、色彩/字体、运动、章节与声音策略，以及相对前作有何变化。不要跨项目搜索无关私人文件。

“换城测试”：替换城市名、照片后，设计是否完全不需变化？如果是，检查是否缺乏本次素材依据。通用的可读性与工程组件可以复用，表达结构不能总是原封不动。

“去装饰测试”：去掉贴纸、纹理后是否仍有主次与阅读路径？若没有，说明依赖表面包装。

“同片一致性”：每章有差异但仍像一支片；不得为了不重复让所有章节彼此冲突。用户喜欢的已验证方法可以复用，不为求新硬改一切。

## 研究证据规则

参考片按页面资料、抽帧、连续观看、实际听审分别标记。记录具体源时间、可见事实、可迁移方法、局限与不适配项。完整作品、短片头、教程、实体手账分开分类。搜索命中数量不能当学习成果数量。真实照片的技术质量与原作者未公开的选片过程不能靠低清抽帧推断。
