# 按天、按地点与同期声串联

按天、按地点与事件主线都是正式选项，不能因偏爱故事化而排斥清楚的日记结构。用户可能提供部分行程，也可能完全不记得；完整口述不是使用前提。

## 选择章节尺度

- 日期清楚、每天内容明显不同：Day 1 → Day 2 → Day 3；每天内部再按地点或事件组织。
- 多个目的地且各有充分素材：城市/景点分章；同一地点跨天时可合并，但不伪装为连续一天。
- 一天跑很多地方：以天为大章，地点是小段，不必每处都加完整片头。
- 一个地方拍很多天：避免每天重复相似内容，可用活动组织；若用户希望按天，仍优先遵循。
- 日期不可靠：先按可确认地点或事件分章，使用“沿途”“海边”“街上走走”等真实但不冒认地名的表达，不制造 Day 2。

每章有主图/记忆重点，篇幅按内容价值分配，不平均分天数。转场可用简短日期地点、路线、环境声或同期声；不是每章都需要复杂动画。缺乏素材的一天可以略过，不能用其他日期的照片填空却标成那天。

## 不依赖用户复述的行程恢复

先读取用户提供的素材和现有行程备注，不主动翻找无关私人聊天、邮件或账户。

1. 保存原始拍摄时间、时区信息、GPS（如有）、设备与文件来源。区分拍摄时间与导出/复制时间；文件名和修改时间仅作弱线索。跨时区、多设备时检查偏差，不盲按时间排序。
2. 识别地点文字、路牌、票根、招牌和可辨识地标；OCR 与视觉识别是候选证据，不能仅凭“像京都”确定地点。地图检索可核对候选地名，但不能证明用户到过那里。
3. 用相邻已确认素材、连续时间、相同场景建立事件组，保留推断标记。不要按服装相同就断定同一天。
4. 输出内部行程表：事件 ID、时间区间、地点候选、依据、冲突、确认状态、源文件。区分用户确认、元数据支持、视觉线索与未知。
5. 对局部不确定项优先采用中性标签继续剪。只有会实质改变主线或重要标题的问题，集中给用户少量代表图和候选，例如“这组是第二天还是第三天？不记得也可以按地点剪”。不要求从头复述旅行。

用户只说出零碎地名也可接收，匹配到事件组后仅更新受影响段落。用户纠正覆盖先前推断，并同步章节、字幕与时间线。路线不完整时不画精确路线动画。

## 同期声作为照片之间的线

用户未来可能随手录说话视频；不要求变成主持人或事先写稿。先转写定位候选，再实际听原声核对意思、语气、噪声与截断；转写文本不能证明听感可用。

候选按作用标注：引入下一地点、描述眼前事物、即时感受、互动反应、回顾收尾。保留自然语气和完整意思，不把几段话拼成用户没说过的观点。

- 声音先进入：上一段末尾先听到真实的“我们准备去……”等话语，再进入对应地点照片。只有实际录到这句话才能使用。
- 声音延续：人物说话画面切到同一事件的照片，声音继续，避免全程只能看口播。
- 语句带照片：按一句话的语义安排整体、细节、反应；不按每个字机械切图。
- 声音比画面好：可用相关照片承载原声，不能拿别人的反应伪装对这句话的回应。
- 没有可用同期声：照片、简短文字、环境声和音乐也可完成结构；不默认合成用户声音或要求补录。

时间线记录音频源文件、源入出点、指涉事件、覆盖照片及跨章位置。背景音乐为说话让位的程度、接缝与环境声连续性需要实际听审，不用固定参数宣称通过。

可选的低负担拍摄提示只在用户需要时给：离开一个地点时随手说一句“在哪儿、刚做了什么、最记得什么”，自然说即可；不设每日打卡、时长配额或强制采访。

研学片的类比用于借鉴“日期/活动/同期声”的结构，不将个人旅行变为课程汇报，也不强加“学会了什么”的总结。
