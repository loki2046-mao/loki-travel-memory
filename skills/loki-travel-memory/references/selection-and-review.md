# 初筛、精选与低负担复选

先读 [本次偏好](user-profile.md)。以下操作参数是建议起点，不是用户已确认的固定配额。

## 分组与排除

先建立“旅行 → 事件 → 拍摄对象 → 相近角度/连拍”的关系。时间、位置和视觉内容联合判断；同一顿饭不同菜品不能只因相似颜色合并，一只不同地点的猫也不能仅按相似外观认作同一只。

原文件只读。标记 `excluded`（不进入本次候选）、`alternate`（备用）、`selected`（入选）、`needs_choice`（少量待选），不永久删除。记录原因和可恢复的原路径。

明显误触黑帧、主体完全糊掉且无独特声音、不可恢复曝光、无关截图等可排除。模糊分数/人脸检测/相似度只负责找疑点，不能替代观看。暗场演出、浅景深食物、夜景不可仅因暗或局部虚焦判废。

唯一合影、独特互动或演出证据单独检查：可缩小展示、短用、保留声音或列入备用，不自动高于一切，也不被批量画质阈值清掉。用途不同的素材分池比较。

## 如何挑“最好的一张”

同角度近重复组，先放大看焦点是否在主体、细节是否糊、曝光是否可用，再比较构图与边缘干扰、光线层次、颜色与材质、主体特征。清晰但平庸不必胜过清楚且光线生动的照片。不要用文件大小、锐化强度或单一总分冒充审美判断。

| 对象 | 主要比较 | 多张同时保留的理由 |
|---|---|---|
| 菜品/咖啡/面包/物件 | 主体形态、层次、表面质感、色泽、餐具与背景关系 | 一张整体，加能看出不同特点的切面/细节；不同角度有信息增量 |
| 自然景观 | 主次、前中后景、水平线、光线天气质感、遮挡 | 全景与局部、不同光线或人物尺度有差异 |
| 人文景观 | 建筑几何、细节、空间关系与生活痕迹 | 环境与标识/纹样/人的活动互补 |
| 人物/朋友/父母 | 表情、姿态、互动与画面质量 | 不同动作或关系；不把眨眼与表情差混为幽默素材 |
| 演出 | 可辨识的舞台/人物、灯光、事件身份与时刻 | 入场和谢幕不同功能；近重复谢幕照片仍要精选 |
| 偶遇小物/动物 | 有趣动作、主体清楚、与路途关联 | 完整小事件有发展；不是为凑萌宠板块 |

先选一张主图，再挑互补图。不能因为计划四宫格，就从同一连拍硬塞四张。三张全景不同角度但信息相同，通常仍只需主图。可轻修的好构图与无需修但平庸的照片同时评估修复成本，不默认淘汰前者。

## 视频：先选事件，再找区间

完整浏览候选事件或连续查看其关键区间；粗抽帧用于定位，不能证明动作流畅或声音清楚。记录源入出点，检查前后是否切断动作、话语和反应。

| 用途 | 首要条件 | 次要条件与取舍 |
|---|---|---|
| 风景/食物动态衬镜 | 画面、主体动作、稳定性 | 无意义噪音可不用；有意义环境声另外保留 |
| 朋友/父母互动 | 真实内容和完整反应、可理解的同期声 | 画面稍弱可用相关照片覆盖；不要用不同时刻反应制造对话 |
| 演出谢幕/入场 | 事件辨识度、现场气氛与可用声音 | 不强求说话；掌声本身可能有价值，失真爆音另处理 |
| 猫狗/偶遇动作 | 动作有趣且看得明白 | 合理保留等待到反应，不只选最清楚的一秒 |
| 转场镜头 | 有方向/位置/时间信息 | 只有漂亮但不相关的镜头不承担虚假空间关系 |

没有真实听审时 `audio_review=unverified`，不能给出“同期声清晰可用”的已验证判断。

## 用户只处理真正有分歧的少量选择

默认给出 agent 的精选结果，不要求用户审核每个重复组。只有审美接近、记忆意义未知、或影响整段取舍时进入复选。

建议一次只展示一个事件，最多 3 个待选组，每组 2–3 张；提供足够大的图、默认推荐及一句具体差别。数字可随反馈调整。允许“用推荐”“选 B”“都不要”“两张都留”“这段你定”；不能要求用户给每张打分。

先说明“已从多少张筛到多少张，本次只需决定哪些组”。自动应用明确选择，后续只展示尚未解决的项。大批问题时重新筛选、按叙事价值排序，而不是连续发十几批复选。用户选择是偏好证据，不能从一次选夜景就永久推断只喜欢暗调。

高辨识度照片需要全片重复审计：同一 `source_id` 重复默认报错；倒木、特殊地标、同姿势自拍等即使文件不同，也要查看视觉相似性。用户指出疑似重复并要求先看替换时，从未使用素材中做 2—3 个真实版式静帧，保留搭配图和文字位置，给出推荐；确认前不改时间线、不渲染整片。

交付选片表包含 source_id、事件/重复组、状态、主图或辅助图角色、选择理由、技术疑点、待修项、判断证据、用户覆盖。未选清单保留在工程内，不强迫用户阅读。


## 全量覆盖

按实际拍摄日期建立整趟事件索引；某天缺失先查 EXIF 与视频录制、导出时间。联系表浏览、候选放大、连续观看和听审分别记录范围。未选项区分精确重复、明显不可用、同组备选、行程外待定；不把全部未选照片标成劣质。
