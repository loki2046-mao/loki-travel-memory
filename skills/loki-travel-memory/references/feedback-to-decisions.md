# 二十多版返工得到的制作判断

以下是经过概括的经验，不含原始对话、私人媒体或真实行程。按失败阶段组织；不是声称每个修正版都已完成听审或通过整片验收。早期探索、完整影片和末期动态样片的验证范围不能混为一谈。

| 反馈主题 | 应改变的决策 | 落地与检查 |
|---|---|---|
| 早期只剪了少量素材，漏了日期 | 先覆盖所有事件再精选 | 拍摄日期依据、浏览覆盖表、每个未用事件理由 |
| 没有板块与时间感 | 根据旅行动机建立章节与事件 | 恢复顺序，具体地点的小节，用户纠正全工程传播 |
| 背景好一点但仍是贴照片 | 设计照片关系而非换皮 | 每组主图/补充图/下一焦点；先看谁后看谁 |
| 滑动改翻页，仍像相册 | 形式变化未解决叙事 | 无关系图组重组，去掉自动交换位置 |
| 增加数量却变成快闪 | 信息增量与阅读时间共同决定节奏 | 主图完整停留、互补细节局部替换，近重复删除出片资格 |
| 主体裁太满，盒盖留白太多 | 按图裁切而非统一框 | 可裁空白与不可裁主体分开；在实际版面复查脸、盘子、地平线 |
| 视频全高却小，或擅改竖屏 | 统一画幅内重新配置主次 | 不裁关键动作，可配同事件有意义辅图；确不适配就改镜头选择 |
| 同姿势、闭眼、杂物、星空近重复 | 选片质量不靠排版补救 | 同组原图比较，全片相似性复查，重要替换先让用户看候选 |
| 大景被自拍和贴纸遮住 | 内容保护高于装饰 | 先完整展示景，再另起人物；叠层与保护区逐帧检查 |
| 每个文字都像同款牌子 | 四种信息角色各有语法 | 导航稳定、字幕可读、花字情绪化、章节有层级；看小屏对比 |
| DAY/副标题被底色吞掉 | 对比问题不一定是位置问题 | 先换颜色/局部衬底，不擅自推翻获认可位置 |
| 特别的食物或经历没强调 | 花字要有选择地帮助情绪 | 找真实笑点/体验，低密度出现，放负空间，不编评价 |
| IP不对或名称误用 | 身份参照与资产文件名分开 | 使用用户给的IP；累趴要改变姿态表情，不套帅照 |
| 花字早退、字幕残留 | 绑定所有权而非手填相近时长 | with_owner/with_subtitle；整个字底描边一起退 |
| 指物对白提前落在上一景 | 声音桥需要语义约束 | “这个温泉”需同物画面；一般路途心情可跨相关镜头 |
| 短同期声一出BGM就停 | 按声音内容分层混音 | 短语下压乐、连续说话不夹音乐碎片、保留完整语义 |
| 换歌虽无重叠还是难听 | 波形不能证明乐句结束 | 听尾韵和下一曲进入，内容归属与听觉共同决定 |
| 推进一半停、结尾突然没声 | 动作与音乐要完成收束 | 保留动作结果、片尾独立包络，避免压乐回弹后骤停 |
| 景与食物转场强行炫技 | 找真实关系，没关系也可克制切 | 镜头对证据、节奏点、声音桥；不能靠烟雾遮掩跳切 |
| 逐张调色而非整片滤镜 | 先判断再调整 | 每张处理记录，肤色/雪山/夜空/食物分别判断，允许保留原色 |
| 新版看不出提升 | 要有可感知前后证据 | 同事件对照，说明实际变好之处；未证明不扩展 |
| 新版更花反而变丑 | 不牺牲认可基线 | 回退无效方案，避免为了变化增加小字和特效 |
| 后期单焦点接力被认可 | 迁移阅读与交接逻辑 | 主图→细节接管→新辅助补入，一次一个焦点；不复制目的地皮肤 |

## 哪些能通用，哪些不能

通用约束：事实正确、原文件保留、主体清楚、可读字幕、语义完整、明确所有权、诚实记录验证。
可调偏好：圆角/直角、框数量、字体、配乐、片长、花字密度、是否先按天组织。原作者喜欢的圆角不是其他用户必须接受的美术规范。
项目决定：具体歌与事件映射、哪张自拍能用、身体暴露边界、IP、笑点、地名、候选 B。保留在私人工程，不固化进公开规则。
已有认可：保持方向再深化；除非用户要求重做，不以“创新”为由换掉。

这些判断应通过 [制作流程](production-workflow.md)、[旧片升级](revision-and-proof.md) 和现有时间线契约执行，而不是让用户再口述一遍。
