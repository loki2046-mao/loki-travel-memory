# 从新素材到成片：执行与人的参与

这是一套决策工作流，不是渲染引擎。工程内记录证据，给用户只看必要选择与可播放结果。表格可合并到现有工程文件，不要求为了执行 Skill 另造管理系统。

## 0. 先分清任务和实际能力

- 新旅行：先清点全部素材，再设计。已有片改进：先读旧工程并看旧片，按 [旧片升级](revision-and-proof.md) 定位问题；不要重新发明用户已经认可的底板。
- 只有成片没有原片：可以诊断、字幕修订或局部再剪，但不能承诺恢复原画质、替换没拿到的照片、分离干净原声。能读取原工程则先恢复引用。
- 对文件读取、看图、视频解码/播放、听音、转写、字体、渲染做一次小规模真实试跑。记录可用/失败/未试，不能凭“装了工具”声称具备能力。先跑通一张照片、一段视频和音轨的导出，不到整片渲染时才发现不可用。
- 不会听音的宿主应在开工时说明，并约定最后由谁听关键剪口。它仍可完成技术检查和制作，但只能交“声音待听审版”，不能一再交未听审版却宣称完成。不要让用户为此逐张核素材。

## 1. 清点与覆盖：先回答发生了什么

生成素材账本：source_id、原路径、类型、原始拍摄时间/时区/依据、事件、重复组、浏览方式与范围、候选用途、未选理由。EXIF 缺失时保留 unknown，可用前后内容和用户信息建立相对顺序，不能用上传时间补成事实。

照片先全量联系表扫描，再对候选原图放大；视频逐条登记时长、画面事件、音轨是否存在和已审范围。带声音的每条视频都要定位完整话语/动作，不能只看头几帧。音轨存在不等于有对白，ASR 有字不等于听得清。

建立事件覆盖表：日期/事件、素材数、已浏览数、精选数、视频和声音区间、缺口与置信度。新增素材按 ID/哈希增量扫描，回查受影响事件；用户指定的一段文件名范围这样的线索要回到相邻素材连续浏览。未选事件写理由，不能让长素材段落默默消失。相同素材不同导出文件也要排重。

## 2. 故事与精选：问人无法从画面知道的事

先用素材写出简短事件顺序和一条主线，再集中问会改变故事的未知项。用户不复述行程也能继续：不确定地点先用可靠上级地点或省略地名，不制造故事。对缺失的最后一天留一个工程占位，不在成片里编造雪景。

| 谁处理 | 内容 | 给人的最小交互 |
|---|---|---|
| AI 自动 | 排重、技术排除、初选、事件聚类、字幕初稿、版式与调色 | 进度摘要，不要求逐图打分 |
| 用户事实 | 旅行目的、没拍到的背景、同行身份、地名纠正 | 一次集中少量问题，支持语音和不记得 |
| 用户偏好 | 必留时刻、歌曲、暴露边界、IP、重要替换图 | 有推荐的少量候选，已回答不重复问 |
| AI 制作 | 动态样片、工程、混音、预检、修错 | 默认承担可自行决定的细节 |
| 有听觉能力的审阅者/用户 | 完整话语、音乐余韵、过渡听感 | 定位剪口但仍需全片连看；不能只交波形 |
| 用户验收 | 像不像自己的旅行、是否认可审美 | 可播放代表片段和最终版 |

人物选择兼顾清晰、好看与动作差异；不能同姿势铺满一屏，不能为了幽默选闭眼、油光明显或用户不喜欢的状态。食物先整体再细节，同一顿与不同餐分清。近重复星空也要逐张比较。

## 3. 新项目的设计提案必须落到真实素材

输出一页导演卡：旅行主线、观看者、画幅、章节/事件、各段内容重心、音乐用途、2—3 个材料依据、字体角色、主次关系和不要做的效果。用当前照片的色彩、建筑/自然纹理、路线或动作提取视觉语言，不自动沿用冰纹、米色手账或旅游贴纸。

先看同类型参考的真实片段，记下看了哪段、听了哪段、学到的内容关系、素材是否支持迁移；检索页/抽帧不能写成已观看。研究最终要改变一个具体镜头对，不要只列链接和形容词。参考作品的新奇手法没有合适原片就不用。

明确每组照片为什么同屏，以及先看谁、之后看谁。允许全屏、留白、边框和异形，但每个选择需保护主体。每张照片先决定可裁区域，才决定框比例；不是永远不能裁，也不是默认 cover。

## 4. 用最难的连续片段试制

选择能够暴露本片风险的内容组合，如照片多且有对白的吃喝段、竖视频接全景、一个换曲边界；不要只挑最漂亮的风景证明成功。时长以读清图组、听完整话语和一个边界为准，通常约 20—45 秒；不能硬塞固定时长截断句子。若是局部修正可更短。

用真实照片、真实歌曲区间和实际转场渲染；先验证内容，再检查关键转场中间态，最后连续播放。用户已认可视觉方向时只做有风险部分，不每轮要求重选风格。样片通过后扩展全片，不能用样片替代承诺的完整视频。

## 5. 完整制作与收尾

每个章节写信息任务而不是只写地名：交代抵达、看清一个主景、认识一顿饭、保留一个互动等。快慢来自信息量、动作和情绪：重复角度删掉；有增量的细节可连切；大景和完整话语留阅读/呼吸时间。不要把一千张照片当成需要全部塞入的指标。

逐图判断曝光/色温/肤色/高光与相邻镜头一致性；无需调整也记录“原片保留”，不为履行调色要求强行改坏。动态视频同样检查色彩与 HDR。每次纠正进入项目事实表，再同步角标、字幕、解说、音乐所属事件和时间线，不靠手工改一处。

交付：可播放成片、可恢复工程、媒体清单、音乐署名和来源、选择/修订记录、审查范围与未完成项。保留获认可基线；封面、结尾和署名各有用途，音乐要有真正的收束。不要将文件导出成功当成质量通过。

城市吃喝素材的具体决策示例见 [从素材到镜头](city-food-worked-example.md)。这是虚构示例，不替代真实样片。
