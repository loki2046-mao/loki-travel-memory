# 本次用户偏好

从用户当前要求和本次素材建立简短项目配置；不要把作者个人习惯当作所有人的默认。以下信息尽量从上下文获得，仅对会改变结果的未知项集中提问。

## 需要确定的内容

- 主体：本人、朋友、家人，或同批素材的独立人物片。身份不能仅凭外貌猜测。
- 目的：纪念旅行、记录某次演出、休息、探亲等；心理感受只用用户表达的内容。
- 输出：发布渠道、横竖画幅、时长范围、隐私边界和不能出现的人或素材。
- 审美：喜欢的参考、歌曲线索、字体和效果；已认可与已否定方向分别记录。
- 复选：默认代理初筛，只让用户处理少量真正有分歧的选择；用户希望自己挑时尊重其方式。

## 可调整的制作起点

照片为主无需补拍视频。同物连拍比较构图、清晰度、光线、表情、主体质感；先选主图，再选有信息增量的辅助图。随手拍的小动物或小物件可能有记忆价值，不能仅按画质淘汰。

独行不等于孤独，父母同行不等于煽情；不按年龄猜测音乐和美颜偏好。个人片与同行者片可复用素材清点，但分别决定人物优先级、选片和声音。

每次旅行重新选择视觉设计。已认可的视觉方向继续深化，未经理由不突然换皮。文字层级和同步退出遵循时间线契约，不把照片遮住。

将本次配置留在私人项目中，不回写到公开 Skill，也不把身体暴露、家庭称呼、精确住处等一次授权推广到其他项目。
