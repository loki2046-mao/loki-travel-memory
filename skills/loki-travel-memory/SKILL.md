# Loki 旅行回忆片

用户交出素材后，由 agent 承担清点、筛选、叙事、设计、剪辑、声音、修改和验收。默认少打扰；只有记忆意义、人物身份或审美接近且会改变成片时，才给少量候选。照片为主是正常输入，不要求用户补拍大量视频或重新整理完整行程。

公开版 v1.0.0。提供制作判断、版式与动态语法、时间线契约和审计脚本；不附带私人媒体、商业歌曲或剪辑引擎。先检查宿主是否能读取媒体、查看图像、处理视频、转写与输出成片；缺少能力时明确可完成部分，不把文字方案称为成片。

## 制作约束

1. **先看完素材再定结构。** 照片按 EXIF `DateTimeOriginal`，视频区分录制时间与导出时间；上传日期和文件修改时间不能代替拍摄时间。先形成整趟事件索引，再决定按天、地点、事件或情绪组织。
2. **先精选再排版。** 同景、同物、同姿势和连拍先比较构图、光线、表情、主体质感与信息增量。不得为了四宫格凑四张，也不得靠快闪消化大量近重复照片。
3. **照片主导，但视频出现时要有主位。** 视频承担动作、环境声或同期声时，应占主要观看面积；竖屏素材在统一横屏中重构布局，不能只放到全高后留下大片无意义底板。
4. **每趟旅行重新定美术方向。** 从目的地、真实照片、旅行目的与用户明确表达的心情提取设计语言；不能复用固定旅行模板、只换底色，或把纯白、米色、黑色当万能底板。
5. **照片关系先于动效，转场只交接一个焦点。** 主图、细节图、人物与环境要有阅读顺序。每个相邻场景先找动作、方向、形状、光色、尺度、主体或声音的真实连接，再决定直切、声音桥、匹配剪辑、遮挡或图形变形。一次交接默认只让一个主图接管，其他图保持、淡出或退出；不能让多张照片同时穿越、换位或争抢视线。
6. **内容保护高于版式炫技。** 先标出脸、食物、湖面、山脊、建筑主体和关键动作等不可遮挡区域。重要大景先完整展示，再另起一拍看人物或自拍；不能用底部自拍条、花字、小图或导航遮住画面真正要表达的内容。
7. **文字先分角色，再控制密度。** 章节副标题、日期/地点角标、同期声字幕、花字必须一眼可区分。每个画面只承载一个主要信息；保留必要导航，强调花字通常至多一组。01/02/03/04 等编号只有承担真实进度或观看顺序时才使用。删掉复述画面的碎字，文字不能与底板同色被吞掉，也不能遮挡主体。
8. **花字、字幕与画面按所有权同步退出。** 花字绑定照片、视频动作或字幕；绑定字幕时结束误差最多一帧，绑定画面时随同一转场离开。不得提前消失、晚退或在下一镜悬空。具体记录和自动检查见 [时间线与验收契约](references/timeline-review-contract.md)。
9. **配乐从用户指定线索出发，换曲服从真实边界。** 选定歌曲后按实际音源、乐句、强弱、内容与原声重新排剪；节拍检测只提供候选点，不能代替听感。下一首歌不能在上一段画面仍未结束时提前进入；短同期声下保留低位音乐，连续说话不穿插几秒音乐碎片，不重叠两段同期声。未实际人工听审时明确写未完成，不能用 ASR、波形或解码成功冒充。
10. **每张入片照片单独调色。** 按原片曝光、色温、黑白场、主体和场景决定参数；人物保肤色、食物保质感、夜景保黑位、星空不抬灰、雪山与水面保高光。同一事件保持连续，但不整片套一个滤镜。
11. **静帧只验证构图，连续动态样片才验证转场。** 对辨识度高、疑似重复或用户在意的照片，先用未使用素材做 2—3 个真实版式候选并给推荐；静帧方向确定后，用真实音乐和真实素材渲染一段连续样片，抽取转场前/中/后帧并实际播放，再扩展全片。不能拿几张设计稿证明运动已经成立。

## 制作顺序

1. 建立只读素材清单、拍摄日期、Live Photo 配对、视频时序和重复组；记录实际浏览范围。
2. 从所有素材恢复事件表，必要时只问会改变故事或地点判断的问题。用户纠正覆盖先前推断，并同步标题、角标、字幕与时间线。
3. 写一句本次旅行主线，确定“天 → 地点/事件”或其他合适层级；恢复具体地点和用餐事件，不能用一个目的地总称角标覆盖全程。
4. 完成主图、辅助图、视频和原声候选；自动处理明确项，把真正有分歧的少量选择分批给用户。
5. 先选择本次的主叙事模式和次叙事模式，再建立视觉系统：一个有素材依据的核心母题、颜色、字体层级、图框、2/3/4 图语法、视频主位、文字角色、花字语法、章节转换、信息密度曲线，以及明确不用的效果。从已验证的“逐张全屏曝光、主图＋异形细节接力、先景后人、主菜＋热乎细节”中按内容选用或变奏，不机械套版。为主图标出内容保护区，为文字设密度预算；每章只设少量“英雄转场”，其余剪口服务阅读。
6. 建立镜头对接表和可重建时间线，给媒体、转场、字幕、花字、角标、音乐和同期声明确起止、所有权、焦点交接、保护区、匹配依据、实际音乐提示点与声音桥；运行 `scripts/audit_timeline_contract.py` 做静态检查。
7. 先渲染一个含照片组、真实配乐、一次焦点交接和一次章节/换曲边界的连续动态样片；抽查转场 25%/50%/75% 帧，并实际播放检查视线、节奏和剪口。样片成立后再扩展完整横屏片并逐张调色。
8. 按 [时间线与验收契约](references/timeline-review-contract.md) 检查重复照片、裁切、内容遮挡、焦点数量、转场、文字层级、花字/字幕/画面同步退出、音乐换曲、同期声进出和片尾收束。
9. 交付成片、观看页、可重建工程、音乐来源、逐图调色记录、未选/备用清单、审片证据与仍未验证项。技术通过、机器复核、连续播放、人工听审和用户认可分别记录。

## 编辑边界

- 家庭片保留人物行动与关系，不自动写衰老、孝道、亏欠或伤感旁白；独行也不自动等于孤独或疗愈。
- 不伪造行程、对白、地点、拍摄关系和因果；无影像的菜品或活动不拿其他日期画面冒充。
- 低画质但不可替代的素材可以短用、修复或只留声音；未入片不等于删除。
- 用户需要个人 IP 时，要求提供本次可用的参考图；不复用他人的 IP、照片或家庭称呼。
- 避免以冰雾、蒸汽翻页等可见遮罩硬连无关事件。优先内容匹配、自然叠化、声音先行或直接切；没有内容理由时不为“帅”叠特效。
- 不继承课程视频的关注片尾、固定快剪、大字花字或固定字幕尺寸。

## 项目与素材边界

在用户指定的工程目录保存结果；原素材只读，未入选不等于删除。不把原片、GPS、人物身份、行程索引、转写原文、凭证或运行日志提交到公开仓库。第三方服务上传需遵循宿主权限和用户对素材的授权。

公开分享 Skill 不等于授权公开影片和音乐。区分用户确认、抽帧、连续观看、真实听审、算法检测和推断；未完成项明确保留。
